CLAUDE DAILY TEFAS DATA RULE

For TEFAS quantitative screening, use TEFAS_DAILY_DATA.csv in this folder as the primary screening universe.

Key fields:
- return_5d_pct vs previous_5d_pct: non-overlapping short-term momentum comparison
- return_20d_pct vs previous_20d_pct: non-overlapping medium-term momentum comparison
- acceleration_5d_pp / acceleration_20d_pp: recent acceleration
- return_60d_pct / return_126d_pct / return_252d_pct: medium/longer performance context
- volatility_20d_ann_pct: short-term annualized volatility
- max_drawdown_60d_pct: recent downside
- distance_from_60d_high_pct: how extended the move is versus its 60-day high
- investability_hint: heuristic only; VERIFY_ELIGIBILITY must be independently checked before an actionable recommendation
- is_current: false means the fund's latest record may be stale/inactive
- portfolio allocation columns are the latest available TEFAS breakdown when present

Do not treat theme_hint or investability_hint as verified official classifications. They are heuristic labels generated from the fund name.

Screen the entire file before doing web research. Then use KAP, TEFAS, fund manager disclosures and reliable current sources to validate shortlisted candidates, eligibility, catalysts and risks.
